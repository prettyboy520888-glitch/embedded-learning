# 51单片机定时器/计数器学习笔记 (重点：Timer 0, Mode 1)

## 1. 核心概念：什么是定时器？
定时器是单片机内部的“私人助理”，它的工作非常单纯：**只负责数数**。
* **功能分类**：
    * **定时器 (Timer)**：数单片机内部的“心跳” (系统时钟 SYSclk)。因为心跳频率固定，所以数数等于计时。
    * **计数器 (Counter)**：数外部引脚 (T0 pin) 的信号。外面来一个脉冲，它计一个数。

---

## 2. 工作模式 1 (16位定时器模式)
这是最常用、最重要的模式。

* **结构**：由两个 8 位寄存器 **TH0 (高8位)** 和 **TL0 (低8位)** 串联组成。
* **计数范围**：16位二进制，即 $0 \sim 65535$ ($2^{16}-1$)。
* **溢出 (Overflow)**：
    * 当计数器计满 **65535** 后，再来 1 个脉冲，数值瞬间变回 **0**。
    * **动作**：硬件自动将 **TF0 (溢出标志位)** 置 1，并向 CPU 申请中断。

---

## 3. 时间与初值计算 (关键！)

### A. 一个脉冲代表多长时间？
标准 51 单片机遵循 **12分频** 规则：
$$\text{机器周期} = \frac{12}{\text{晶振频率}}$$
* **典型案例**：如果晶振是 **12 MHz**：
    * $12 \div 12 = 1 \text{MHz}$
    * **结论**：定时器每过 **1 微秒 (us)** 计一个数。

### B. 初值怎么算？
因为定时器是**向上计数直到溢出**，所以我们不能从 0 开始，必须预先装入一个**初值 (Initial Value)**。
* **公式**：
    $$\text{初值} = 65536 - \text{你想要的计数值}$$
* **举例**：定时 **50ms** (50,000us)
    * 需要计 50,000 个数。
    * 初值 = $65536 - 50000 = 15536$。
    * **拆分存入寄存器**：
        ```c
        TH0 = 15536 / 256; // 取高8位
        TL0 = 15536 % 256; // 取低8位
        ```

## 4. 中断系统 (紧急处理中心)

### A. 流程逻辑
1.  **溢出**：计数器满了 $\rightarrow$ 变回 0。
2.  **举旗**：硬件把 **TF0** 置 1 (门铃灯亮)。
3.  **判断**：检查两道开关 (**ET0** 和 **EA**) 是否打开。
4.  **响应**：CPU 暂停主程序 $\rightarrow$ 执行中断服务函数 (`interrupt 1`)。
5.  **恢复**：硬件自动把 **TF0** 清零，CPU 回到主程序。

### B. 两道关键开关 (在 IE 寄存器中)
* **EA (Enable All)**：总闸。`EA=1` 才能使用任何中断。
* **ET0 (Enable Timer 0)**：分闸。`ET0=1` 才能使用定时器 0 中断。

---

## 5. 寄存器“控制面板” (Cheat Sheet)

| 寄存器 | 名称 | 关键位 | 作用 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| **TMOD** | 模式寄存器 | **M1, M0**<br>**C/T** | 选择模式1 (01)<br>0=定时，1=计数 | **不可位寻址**<br>需一次性赋值 (如 `0x01`) |
| **TCON** | 控制寄存器 | **TR0**<br>**TF0** | 1=启动，0=停止<br>溢出标志 (门铃) | **可位寻址**<br>可直接写 `TR0=1;` |
| **TH0/TL0** | 数据寄存器 | - | 存放计数的初值 | 每次溢出后需**手动重装** |
| **IE** | 中断允许 | **EA**<br>**ET0** | 总中断开关<br>定时器0开关 | **可位寻址** |

---

## 6. 代码实战模板 (Timer 0, 50ms)

这是把所有知识点串起来的标准写法：

```c
#include <reg52.h>

// 1. 初始化函数
void Timer0_Init()
{
    // A. 设置模式 (TMOD)
    // 设置 T0 为模式1 (16位定时)，且不影响 T1 (使用按位或/与操作更安全)
    TMOD &= 0xF0; // 把低4位清零
    TMOD |= 0x01; // 把低4位设为 0001
    
    // B. 装入初值 (50ms @ 12MHz)
    TH0 = (65536 - 50000) / 256;
    TL0 = (65536 - 50000) % 256;
    
    // C. 打开溢出标志位 (清零是一个好习惯，虽非必须)
    TF0 = 0;
    
    // D. 打开中断开关 (IE)
    ET0 = 1; // 打开 T0 分开关
    EA = 1;  // 打开 总开关
    
    // E. 启动定时器 (TCON)
    TR0 = 1;
}

// 2. 中断服务函数 (interrupt 1 代表定时器0)
void Timer0_Routine() interrupt 1
{
    // 【重要陷阱】：必须手动重新装载初值！
    // 否则下次会从 0 开始计，变成 65ms
    TH0 = (65536 - 50000) / 256;
    TL0 = (65536 - 50000) % 256;
    
    // 这里写每 50ms 要做的事情
    // 例如：P2_0 = !P2_0; // LED 翻转
}

void main()
{
    Timer0_Init(); // 记得调用初始化
    while(1)
    {
        // 主循环，做其他事情
    }
}
